# Ritmo a primera vista

Aplicación web sencilla para practicar la escucha y la repetición de ritmos.

## Acceso web

[Abrir Ritmo a primera vista](https://hugovalesf.github.io/GotRythm3/)

## Uso

Abre `index.html` en un navegador moderno y pulsa **Empezar** para iniciar el audio. No requiere instalar dependencias ni ejecutar un servidor.

- Cada patrón tiene cuatro pulsos y se practica durante cuatro compases.
- El primer compás reproduce el patrón de hi-hat, caja y bombo junto al metrónomo.
- En los tres compases siguientes solo suena el metrónomo para acompañar la repetición.
- Al empezar un nuevo ciclo de cuatro compases se genera un patrón aleatorio distinto; no se repite hasta recorrer las ocho combinaciones posibles y el ejercicio continúa hasta detenerlo.
- **Nuevo ritmo** genera otro patrón y el control deslizante ajusta el tempo entre 40 y 200 BPM.
